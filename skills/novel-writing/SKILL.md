# 連載小說寫作技能

給長篇連載用：一章一章寫、靠檔案記住設定，不靠對話記憶。這份技能只放通用流程；每個作品自己的檔案路徑、固定格式、口癖和禁用名稱，寫在專案根目錄的 `novel.config.md`。

## 0. 先找專案設定

1. 在專案根目錄找 `novel.config.md`。找不到就用 `references/project-config-template.md` 幫作者建一份，問清楚空白欄位再開始寫。
2. 設定檔裡指到的「事實登記表」不存在時，用 `references/facts-template.md` 建一份。
3. 設定檔寫的規則優先於這份技能的預設值。

## 參考文件地圖

| 什麼時候 | 讀哪份 |
|---|---|
| 開新書、開新卷、改大綱 | `references/planning.md` |
| 寫完一章 | `references/self-check.md` |
| 改稿、潤稿、每十章體檢 | `references/revision.md` |
| 想學某本書的結構 | `references/deconstruct.md` |
| 某個主題要查更細的做法 | `references/library/README.md`（第三方原文，依主題索引） |

## 1. 寫之前讀什麼

一次最多讀四類，不要把整本書讀進來：

| 類別 | 用途 |
|---|---|
| 事實登記表 | 時間線、數字、人物習慣、資訊邊界、伏筆、各章結尾型態、每章新定下的事。正文出現的數字沒登記就不能用。 |
| 角色外型單 | 外貌、服裝、隨身物。有插圖的作品以定稿圖為準。 |
| 用詞表 | 專有名詞與譯名。 |
| 前一章正文 | 接語氣、接最後一個場景。 |

## 2. 寫一章

1. **對照**：讀事實登記表的時間線、資訊邊界、上一章的結尾型態、還沒兌現的伏筆。寫下這章要推進的那一件大事（見自檢第 1 節）。
2. **拍子表**：照 `references/planning.md` 第 4 節列 4 到 8 拍，每拍一個場景的進展。
3. **寫正文**：照設定檔的檔名格式與章首格式存檔。章內換場用設定檔指定的分隔符。
4. **自檢**：跑 `python3 scripts/check_chapter.py --config <專案>/novel-check.json <章節檔>`（沒有設定檔就省略 `--config`），再照 `references/self-check.md` 人工看一遍。
5. **登記**：在事實登記表新增這章一節：日期、新名字、新數字、資訊邊界變化、結尾型態。新名詞進用詞表。有建時間線檔的話，把這章的事件加進去，跑 `python3 scripts/check_timeline.py <timeline.json>`。另外在摘要檔補這章三到五行摘要。
6. **周邊**：設定檔列了每章要附的檔案（預告、社群貼文、插圖需求等）就照做。
7. **交接**：設定檔有翻譯或其他下游，通知它們；之後改稿要列出改了哪幾句。

## 3. 改稿

- 只改被指出的地方，不順手重寫整段。
- 改到已經交給下游（翻譯、排版、已上線）的章節，列出「舊句 → 新句」。
- 改到事實（日期、數字、名字），同步改事實登記表和已發布的版本。
- 潤稿用兩遍法，修問題前先分清楚哪些能直接改、哪些要問作者，見 `references/revision.md`。
- 每寫滿十章做一次體檢（壓縮摘要、文風校準、伏筆盤點、重複檢查、時間線驗算），見 `references/revision.md` 第 3 節。

## 4. 審稿

照 `references/self-check.md` 的順序：節奏、事實與時間線、因果與資訊邊界、結尾、語言、名字。只報有問題的項目，每條寫原句、問題、最小改法。不為填滿檢查表而要求加戲。

## 5. 角色與設定擴充

- 新角色、新元素先當「候選」，編號給作者挑。作者選了才寫進事實登記表和外型單。
- 起名規則見自檢第 7 節。

## 6. 匯出電子書

一卷寫完可以匯出 EPUB：

```bash
python3 scripts/export_epub.py --title 書名 --author 作者 --cover 封面.jpg --out 書名.epub 章節1.md 章節2.md ...
```

## 7. 預設不做、可以在設定檔打開的事

- 每章結尾留鉤子：預設不強制，結尾型態輪替。設定檔把「結尾」設成 `hook` 才改成每章留鉤子。
- 事件冷卻、開頭三章規則：預設關，長篇或平台連載可以打開，見 `references/planning.md` 第 5、6 節。

## 8. 一律不做的事

- 不設字數下限，篇幅以作者定下的範本章密度為準（設定檔可以寫平台要求的範圍）。
- 不呼叫外部 API、不需要金鑰；檢查程式只用 Python 標準函式庫。
